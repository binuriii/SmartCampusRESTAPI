Smart Campus API

Base URL: /api/v1

Note: Please use Postman or curl for POST and DELETE operations.

Note: Please replace path variables like {roomId} or {sensorId} with actual values (e.g., use a real room ID).

Endpoints

GET /api/v1 - Discovery End Point
GET /api/v1/rooms - Get all rooms
POST /api/v1/rooms - Create a new room
GET /api/v1/rooms/{roomId} - Get room by ID
DELETE /api/v1/rooms/{roomId} - Delete a room
GET /api/v1/sensors - Get all sensors
POST /api/v1/sensors - Create a new sensor
GET /api/v1/sensors?type=CO2 - Filter sensors by type
GET /api/v1/sensors/{sensorId}/readings - Get sensor readings
POST /api/v1/sensors/{sensorId}/readings - Add a new reading
